## Sobre mim

Sou **Pedro Queiroz**, estudante de **Ciência da Computação no Senac Nações Unidas** e desenvolvedor de software em São Paulo. Desenvolvo aplicações web e desktop com **React, TypeScript, Node.js, C# e C++**, publicadas como projetos open source ou entregues a clientes como freelancer.

**Busco estágio ou vaga júnior em desenvolvimento de software.** Também atendo projetos freelance de sites, sistemas web e automações.
